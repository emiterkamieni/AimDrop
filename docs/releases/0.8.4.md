# AimDrop 0.8.4

## Update directly in AimDrop

**Check for Updates… → Update and Restart** now downloads, verifies and installs
new releases in the app. Both the update archive and feed carry Ed25519 signatures.
Scheduled checks run every 24 hours and only notify; installation requires your click.

- Updates replace the exact running copy, including an app launched from `dist`.
- Restart waits for accepted transfers, saves, Trash operations and an already-open
  destination picker. New operations are blocked during restart preparation.
- Unsaved settings can be saved, discarded, or used to cancel the update.
  A settings-save error prevents restart.
- Ready, unsaved transfers and existing settings and pairing survive the update.
- Update windows use AimDrop's selected language and shared button style.

## More control over received files

- **Unsaved transfers** lists waiting batches with file names, dates and retention deadlines.
- Save or move individual batches to Trash, or use **Delete All** with confirmation.
- Hover over file names for lightweight image, document, video or text previews.
- Automatic inbox cleanup defaults to **7 days**, with an adjustable period and an off switch.
- Action buttons share a consistent 28-point style; avatar actions have clearer names.
- Launch at login is enabled by default for new installations and respects later opt-outs.
- All 15 language catalogs have been updated.

## Installation and compatibility

- **Local 0.8.3 users:** install this release from AimDrop's update menu. This release
  increases the internal build number from 23 to **24** and keeps the same update key.
- **Public 0.8.2 and earlier users:** install this release manually once. Future
  releases can then be installed directly in the app.
- Requires an **Apple Silicon Mac with macOS 26 or later**. Python is bundled.
- The app remains ad-hoc signed. For a first manual installation, macOS may require
  **System Settings → Privacy & Security → Open Anyway**.

Download **AimDrop-0.8.4-macos-arm64.zip** and verify it with **SHA256SUMS**.
The attached **appcast.xml** is the signed feed used by the in-app updater.
End users do not need access to the publisher's signing key or Keychain signing dialogs.
